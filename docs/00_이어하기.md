## 구조 요약
- 자막 자료 = 음성 ST2 **머리**에 DSUB 묶음(데이터 시작 +4 를 늘리고 +0xC 길이도 같이) — 머리 처리기 0x060147DC 의 memcpy 리터럴 0x060148EC 를 훅. 머리는 무음으로 재생되므로 시각에 머리/735 프레임 보정.
- 시계 = 0x06046E74(음성 재생 위치, 1/60초). E80 은 «보이는 컷» 시각이라 쓰면 안 됨.
- 코드 = BLDANIM 끝 블롭 → 진입 리터럴 0x06010010 토막이 0x06049000 으로 복사(BSS 0x0602F850‥0x060488D0 밖) · VBI 리터럴 0x06018178 감싸개.
- 그리기 = `tools/hook.py`(VDP1 8비트 선형 그림 0x25C7A000 + 확대 스프라이트 명령을 명령표 END 자리에). 검산 `tools/test_vdp1.py`.
- 쪽 글자 번호 9비트(음성당 서로 다른 글자 ≤ 511). 묶음 ≤ 32 KB(가장 큰 S16100 9.3 KB).
- 디스크 = `tools/iso.py relayout`(전 파일 LBA 순서로 다시 잇기, DIN_TRY 는 늘어난 만큼 이동, PVD).
